# Hier stand `Disallow: /_next/static/chunks/`.
#
# Die Sperre nahm dem Renderer von Google genau die JavaScript-Bundles weg, die
# er braucht, um die Seite so zu sehen wie ein Besucher. Google meldet das als
# blockierte Ressource und rendert im Zweifel eine unvollständige Seite. Für
# eine Domain, deren Hauptproblem fehlende Indexierung ist, ist das die
# teuerste Zeile im ganzen File. Die Chunks enthalten nichts Vertrauliches --
# jeder Besucher lädt sie ohnehin.

# Hier stand `Disallow: /*?*` mit drei `Allow: /*?utm_...`-Ausnahmen darunter.
#
# Die Regel kappte sämtliche URLs mit Query-Parameter. Die Ausnahmen darunter
# greifen bei Google nicht zuverlässig, weil `Disallow` und `Allow` gleicher
# Spezifität miteinander konkurrieren -- eine Kampagnen-URL konnte dadurch
# ungewollt aus dem Index fallen. Duplikate löst stattdessen das
# `canonical`-Tag, das jede Seitenvorlage dieses Projekts setzt.
