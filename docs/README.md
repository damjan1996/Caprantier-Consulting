## Grundsatz

Diese Dokumente sind Nachweise, keine Werbetexte. Felder, die noch nicht
belegt sind, bleiben leer oder tragen einen ausdrücklichen Hinweis. Eine Zeile,
die einen Vertrag oder eine Prüfung behauptet, die es nicht gibt, richtet mehr
Schaden an als eine offene Lücke — sie wird bei einer Prüfung zur falschen
Auskunft.

Verträge, Protokolle über Betroffenenanfragen und andere Unterlagen mit
Personenbezug gehören **nicht** in dieses Repository.
